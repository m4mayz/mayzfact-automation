# Brand MayzFact

Logo MF: huruf M dan F nyatu, miring 10°, kaki kanan M sekaligus jadi batang F. Lengan F (dari "Fact") warnanya kuning. Dipilih Akmal tanggal 2026-10-15.

Arahnya seru dan energik, nyambung sama gaya video: font Anton kayak di caption, dan kuning kayak panah penunjuk.

## File

| File | Dipakai buat |
| --- | --- |
| `profile-800.png` | YouTube Studio > Customization > Branding > Picture |
| `banner-2048x1152.png` | Customization > Branding > Banner image. Logo dan tagline ada di area aman 1235×338, jadi kelihatan di HP, desktop, sama TV |
| `watermark-300.png` | Customization > Branding > Video watermark (minimal 150×150, di bawah 1 MB) |
| `channel-description.txt` | Customization > Basic info > Description |
| `mayzfact-symbol.svg` | Simbol berwarna, khusus buat latar gelap |
| `mayzfact-symbol-white.svg`, `mayzfact-symbol-black.svg` | Versi satu warna: putih buat di atas foto/video, hitam buat latar terang |
| `mayzfact-lockup.svg`, `mayzfact-lockup-dark.png` | Simbol + tulisan MAYZFACT |
| `*.svg` lainnya | Sumber vektor buat file PNG di atas |

## Warna

| Nama | Hex | Dipakai buat |
| --- | --- | --- |
| Ink | `#0B1020` | Latar |
| Yellow | `#FFD400` | Lengan F, kata yang disorot |
| White | `#FFFFFF` | Huruf M, teks |

Kontras di atas Ink: putih 18,9:1, kuning 13,2:1. Kuning jangan ditaruh di latar putih karena kontrasnya rendah. Di latar terang, pakai versi hitam.

## Font

Anton (SIL Open Font License), font yang sama kayak caption video. Semua teks di SVG udah diubah jadi path, jadi nggak perlu file font.

## Aturan pakai

- Simbol berwarna cuma dipakai di latar gelap.
- Kasih ruang kosong di sekeliling logo, minimal setebal lengan F.
- Jangan tampilkan simbol lebih kecil dari 24 px.
- Jangan ubah kemiringannya, dan jangan tambahin glow, gradasi, atau bayangan.
